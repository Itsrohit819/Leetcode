# 🧠 LeetCode Contest Solutions

This repository contains my personal solutions to **LeetCode Weekly and Biweekly Contests**.  
All problems are solved during the live contests or shortly after, written in C++.

---

## 📁 Structure

```
leetcode-contests/
├── Weekly_401/
│   ├── Q1.cpp
│   ├── Q2.cpp
│   ├── Q3.cpp
│   └── Q4.cpp
├── Biweekly_128/
│   ├── Q1.cpp
│   ├── Q2.cpp
│   └── ...
...
```

- Each folder is named based on the contest name.
- Filenames are `Q1.cpp`, `Q2.cpp`, etc., representing the order of problems in the contest.

---

## 🛠️ Tech Stack

- **Language:** C++
- **IDE:** VS Code / Sublime / Custom Competitive Template
- **Style:** Minimal, clean, with macros and STL

---

## 🚀 How to Run

1. Clone this repo:
   ```bash
   git clone https://github.com/Itsrohit819/leetcode-contests.git
   ```
2. Navigate to a specific contest folder:
   ```bash
   cd Weekly_401
   ```
3. Compile and run:
   ```bash
   g++ Q1.cpp -o Q1 && ./Q1
   ```
